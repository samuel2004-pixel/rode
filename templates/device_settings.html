Biometric Device Settings

Find this on the device: Menu \u2192 Comm. \u2192 Ethernet. Set it to a fixed/static IP so it doesn't change.
Default ZKTeco port is 4370 - leave as is unless you changed it.
Leave as 0 unless you set a communication password on the device.
How this works
  1. Make sure the biometric device is connected to the same Wi-Fi/LAN as this computer.
  2. Enter the device's IP address above and click Test Connection.
  3. Go to Students \u2192 Link Biometric IDs to match each fingerprint already enrolled on the device to a student record.
  4. On the Attendance page, click Sync from Biometric Device for any date - students who punched that day are marked Present automatically.

Fingerprint enrolment itself (registering a person's finger) is still done on the device's own menu, as usual - this app only reads the punches and the enrolled user list.
